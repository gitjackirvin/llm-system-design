3.9.) Metrics Tool: Prometheus (Open Source) (Free)
Explanation: Prometheus is a time-metrics collecting system that collects real time data from all the different components of the LLM system. It gathers GPU utilization, tokens per second being generated, how long the vLLM queue is for responses, how quick requests get processed by the FastAPI gateway, how much gets processed by each Kubernetes instance, all over a period of time. It can show if you are meeting all your set objectives, give you alerts based on rules you set, find bottlenecks, track performance metrics over long periods of time, and let you see where future expansion is needed.
