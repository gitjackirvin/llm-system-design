3.10.) Metrics Dashboard: Grafana (Open Source) (Free)
Explanation: Grafana is a real-time visualization and dashboard system built on top of metrics from Prometheus. It takes the data from prometheus and turns it into interactive dashboards that update in real-time from user input. There is the ability in Grafana to create custom dashboards for tracking custom metrics for data as well as checking to see if policies you set in place are being violated or not being met. Another feature is that different roles are able to be created in order to allow different users to see different dashboards.
