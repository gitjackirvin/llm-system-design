## **Automation & Workflow**

| Capability | Plugin | Description |
| :---: | ----- | ----- |
| Automatically generate project timelines from all data sources | CrewAI | Builds timelines from documents, tickets, and communications. |
| Build a graph of people, systems, decisions, and dependencies | MCP | Creates a knowledge graph of institutional relationships. |
| Preserve knowledge when employees leave | MCP | Retains decisions, documents, and workflows permanently. |
| Look at websites, extract data, and act on it | browser‑use | Scrapes and interacts with any website. |
| Order food automatically when instructed | browser‑use | Orders food through delivery portals. |
| Interact with any external app, like order food, log into websites | browser‑use | Automates multi‑step web workflows. |
| Automatically create tasks and assign them | browser‑use | Creates tasks in Faveo/Teams. |
| Automatically send reminders to people | LangChain Tools | Sends reminders via email/calendar. |
| Automatically add/remove permissions or onboard users | MCP \+ OpenInterpreter | Manages permissions. |
| Automatically configure pools, storage, and settings | LangChain Tools | Configures Proxmox and storage systems. |
| Deploy infrastructure with Ansible | OpenHands | Executes playbooks. |
| Automated remediation | OpenInterpreter | Applies fixes via scripts or APIs. |
| Security ticket creation | browser‑use | Creates and assigns tickets in Faveo. |
| Auto‑create maintenance tickets | browser‑use | Creates work orders. |
