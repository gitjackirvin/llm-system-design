## **Meetings & Scheduling**

| Capability | Plugin | Description |
| :---: | ----- | ----- |
| Automatically schedule meetings | LangChain Tools | Schedules meetings via Google/Outlook APIs. |
| Automatically record and transcribe meetings | faster‑whisper | Transcribes meetings with timestamps. |
| Generate meeting summaries and action items | Hermes \+ CrewAI | Summarizes discussions and extracts tasks. |
| Create meeting agendas | Hermes | Generates agendas. |
| Summarize administrative meetings | Hermes \+ faster‑whisper | Summaries of meetings. |
