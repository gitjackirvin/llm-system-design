## **Networking & Infrastructure**

| Capability | Plugin | Description |
| :---: | ----- | ----- |
| Generate Cisco configs | OpenInterpreter | Creates IOS/IOS‑XE/IOS‑XR configs. |
| Generate Fortinet configs | OpenInterpreter | Creates firewall policies and NAT rules. |
| SSH into network devices | OpenInterpreter | Executes commands on switches/routers. |
| Add VLANs | OpenInterpreter | Adds VLANs to switches and trunks. |
| Update switchport configs | OpenInterpreter | Configures access/trunk ports. |
| Update firewall rules | OpenInterpreter | Creates or modifies firewall policies. |
| Network modeling | Hermes | Generates network diagrams and topology models. |
| Run Nmap scans | PortWeaver | Executes Nmap and summarizes results. |
| Parse Nessus reports | OpenInterpreter | Extracts vulnerabilities from Nessus XML/CSV. |
| Map CVEs to Metasploit modules | OpenInterpreter | Queries MSF RPC for exploit modules. |
| Analyze Burp Suite traffic | Suite‑o‑Llama | Explains vulnerabilities in HTTP traffic. |
| Analyze PCAP files | OpenInterpreter | Uses tshark to decode packets. |
| Interpret Prometheus alerts | LlamaIndex Tools | Explains alert meaning and root cause. |
| Generate Grafana dashboards | LlamaIndex Tools | Creates full JSON dashboards. |
